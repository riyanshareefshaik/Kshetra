# Kshetra API

FastAPI backend of [Kshetra](https://github.com/riyanshareefshaik/Kshetra). Copy this file to the
root of your Space as `README.md`, together with the repository's `Dockerfile`, `backend/` and
`database/` folders. Set the variables from `.env.example` under *Settings → Variables and secrets*.
